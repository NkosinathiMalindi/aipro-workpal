# AI-Workplace-Helper

Build a fully functional responsive web app called “AI Workplace Productivity Assistant” for non-technical professionals. Create a polished dark modern SaaS dashboard with a sidebar, card-based layout, friendly AI imagery/background and clear icons. Include interactive AI-powered prototype workflows for: Smart Email Generator (tone and audience controls), Meeting Notes Summarizer (key points, action items, deadlines), AI Task Planner (prioritization and scheduling), AI Research Assistant (insights and summaries), and an AI Chatbot. Use structured prompt engineering behind each workflow and return professional, clear outputs. Add loading states, empty states, responsive mobile navigation, and show the disclaimer “AI-generated content may require human review” in relevant output areas. Make the UI intuitive and welcoming for non-technical users. Enable Lovable Cloud if persistent data/auth/backend capabilities are needed; otherwise deliver as a complete interactive prototype.
